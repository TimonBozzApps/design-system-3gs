# @3gs/ui

## 0.1.0

### Minor Changes

- 4bb1a17: Initial release: 23 iOS 3–style React components (Button, Switch, TextField / SearchField,
  NavigationBar / BarButton, TabBar, List, Alert, SegmentedControl, Slider, ActionSheet, Picker,
  DatePicker, ProgressBar / ActivityIndicator, StatusBar, Toolbar, PageControl, Popover, HUD,
  Keyboard, ModalSheet, Stepper, SearchBar, NotificationBanner) plus the Icon / Badge foundation,
  `--gs-*` design tokens, a dark theme (default) and the classic light theme (`data-theme="light"`),
  RTL support and a `GsProvider` for localized strings.
