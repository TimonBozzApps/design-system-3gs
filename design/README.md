# Design export

Everything a designer needs to bring 3GS UI into Figma **without a live Figma
connection**. All files are generated from the library's CSS, so they cannot
drift from the code — never edit them by hand, run the export instead:

```bash
pnpm design:export     # = node scripts/export-tokens.mjs && node scripts/figma-sheet.mjs
```

| File | What it is |
| --- | --- |
| `tokens/3gs.dark.tokens.json` | Every `--gs-*` token of the dark (default) theme in the [W3C DTCG](https://tr.designtokens.org/format/) format |
| `tokens/3gs.light.tokens.json` | The same tokens with `theme-light.css` applied — the classic iOS 3 look |
| `3gs-gel-sheet-dark.svg` | Sticker sheet of the core gel styles, dark theme, drawn as editable vectors |
| `3gs-gel-sheet-light.svg` | The same sheet in the light theme (blue-gray bars, white cells, pinstripe) |

## Tokens (`tokens/*.tokens.json`)

Generated by `scripts/export-tokens.mjs` from `packages/ui/src/tokens/tokens.css`
and `theme-light.css`. The parser resolves every `var()` reference (the light
file is the dark set with the light block laid over it *before* resolution, so
composite tokens such as `--gs-emboss` pick up the light rims exactly like the
CSS cascade does) and classifies each value:

| CSS value | `$type` | `$value` |
| --- | --- | --- |
| `#hex`, `rgb()`, `rgba()` | `color` | `"#rrggbb"` or `"#rrggbbaa"` |
| `linear-gradient(to bottom, …)` | `gradient` | `[{ color, position }]`, position 0–1 (the 49 % / 50 % gel split is kept) |
| `repeating-linear-gradient(…)` (pinstripe) | `gradient` | one period, plus `com.3gs.repeating: true` and `com.3gs.period: "7px"` |
| `box-shadow` / `text-shadow` lists | `shadow` | `{ color, offsetX, offsetY, blur, spread, inset }` (an array when the CSS lists several) |
| `Npx` | `dimension` | `"44px"` |
| unitless number | `number` | `1.2` |
| font stack | `fontFamily` | `["Helvetica Neue", "Helvetica", "Arial", "sans-serif"]` |
| `Nms` | `duration` | `"160ms"` |
| `cubic-bezier(…)` | `cubicBezier` | `[0.25, 0.1, 0.25, 1]` |
| `1px solid …` | `border` | `{ color, width, style }` |
| anything else (`none`) | `string` | the raw value |

Tokens are grouped by the second segment of their name: `--gs-gradient-blue` →
`gradient.blue`, `--gs-font-size-lg` → `font.size-lg`. A bare name whose group
has siblings becomes `<group>.default` (`--gs-text` → `text.default`); a lone
one stays a leaf (`--gs-black` → `black`). Every token carries
`$extensions["com.3gs.css"]` with its CSS custom-property name, and gradients /
shadows also keep the resolved CSS string in `com.3gs.cssValue`. Gradient
direction is in `com.3gs.angle` (180 = `to bottom`, 90 = `to right`). A token
that was written as a plain `var(--other)` alias records it in `com.3gs.alias`.
`$description` comes from the token's CSS comment.

### Importing into Figma with Tokens Studio

1. Open the **Tokens Studio for Figma** plugin → Settings → **Load from file**
   (or *Sync → File* for a local folder) and pick `3gs.dark.tokens.json`. Each
   top-level group becomes a token set; load `3gs.light.tokens.json` the same
   way and switch sets to flip the theme (or use the sets as two themes).
2. **Create styles / variables**: *Tools → Create styles* turns the `color`
   tokens into colour styles and `dimension` / `number` tokens into Figma
   variables (Tokens Studio Pro: *Export to Figma → Variables*).

What imports cleanly vs. what needs a hand:

- `color`, `dimension`, `number`, `fontFamily`, `duration`, `cubicBezier` — as-is.
- `gradient` — Tokens Studio has no gradient type. Paste the
  `com.3gs.cssValue` string (a plain `linear-gradient(...)`) into a **Color**
  token: Tokens Studio understands CSS gradients in colour tokens and creates
  a gradient fill style. Or take the fills straight from the SVG sheet (below).
- `shadow` — DTCG uses `offsetX` / `offsetY` / `inset`; Tokens Studio's own
  box-shadow tokens use `x` / `y` and `type: dropShadow | innerShadow`. Map
  them when creating effect styles (or read the `com.3gs.cssValue`).
- `border` — a composite; use its `color` / `width` parts.
- The `pinstripe.bg` gradient is one 7 px period of a repeating stripe: draw it
  as a 7 × 7 image fill or a component, not as a linear gradient.
- Figma itself has no JSON variable import; the JSON is for plugins
  (Tokens Studio, Variables Import/Export, Style Dictionary pipelines).

## Sticker sheets (`3gs-gel-sheet-*.svg`)

Generated by `scripts/figma-sheet.mjs`, which imports the same parser and
reads the same CSS (plus the component-local custom properties of the switch,
tab bar, alert, keyboard, page control, segmented control, slider and progress
bar), then draws a 1200 px wide spec page on a 24 px grid:

- **Buttons** default / primary / destructive at 44 px with their pressed
  twins, plus the 30 px small size.
- **NavigationBar** 320 × 44 with the pointed back button, title and blue Done;
  the three **BarButton** kinds on their own.
- **TabBar** 320 × 49 (black in both themes) with five gel-gradient glyphs,
  the selected sunken well and the red "43" badge.
- **Switch** ON / OFF, **SegmentedControl**, red / gray **Badge**, **PageControl**.
- Sunken wells: **TextField**, **SearchField** pill, **Slider**, **ProgressBar**.
- **Grouped list** 300 px with icon tiles, chevrons, detail text and a checkmark;
  **Alert** 284 px; **HUD** 140 × 140 with the 12-spoke spinner; a **keyboard
  key** 26 × 39, a function key and the key **popup**.
- A row of **gel swatches**: every gradient / gloss token as a rounded rect
  whose fill is the token's `<linearGradient>` — select one, and the fill in
  the inspector is the exact gel style to save as a Figma paint style.

Every element is a `<g id="…">` (Figma names the imported layer after it),
built from `<rect>` / `<path>` / `<circle>` with `linearGradient` fills that
keep the hard 49 / 50 % split, 1 px inner-rim rects, 1 px outline strokes, and
`<text>` set in Helvetica Neue.

### Importing into Figma

**File → Place image / Import**, drag the `.svg` onto the canvas, or paste the
SVG source (Cmd-V) into a Figma page. Figma converts:

- Shapes, strokes, opacities, `linearGradient` / `radialGradient` fills
  (including the gel split stops) → **editable vector layers with gradient
  fills**. Right-click a gel → *Copy properties* / create a style from its fill.
- `<clipPath>` → mask groups (the switch strip, segmented bar, slider fill).
- `<text>` → text layers, provided Helvetica Neue is available (it is on macOS;
  otherwise Figma substitutes and shows a "missing font" notice).

What Figma **flattens or drops**, and how to restore it:

- **`<filter>` effects are ignored** — the emboss drop edge (`feDropShadow`
  0 / 1 / 0 black 75 %, white 55 % in light), the sunken `--gs-inset` wells
  (inner shadow 0 / 2 / 5 black 75 %), the pressed-state inner shadow
  (0 / 2 / 4 black 60 %), the alert / HUD / popup drop shadows and the knob
  shadows. Re-add them as Figma **Effects → Drop shadow / Inner shadow** using
  the values in the `shadow` tokens (`emboss`, `inset`, `shadow.pop`,
  `rim.dark`). The 1 px light rims *are* geometry and survive.
- Text shadows are drawn as a second, offset text layer (SVG has no
  text-shadow) — merge or delete it if you prefer Figma's text effects.
- The pinstripe is real 1 px stripes (Figma has no SVG `<pattern>` support);
  replace with a 7 px tile fill if you need it to scale.
- The HUD's `backdrop-filter: blur(10px)` has no SVG equivalent — add a
  Background blur effect.
- The tab-bar and list icons are simplified silhouettes standing in for the
  library's lucide glyphs; swap them for the real icons.
